SHIFTY · Editor 0.31

Editor de jugadores · Catálogo público de la beta. Tus diseños se guardan en este dispositivo.

Cada nivel comienza solo con suelo. Toca o haz clic en la cuadrícula para colocar una pieza; arrastra para colocar varias. Usa «Mover vista» para recorrer el nivel. El borrador elimina objetos, nunca el suelo. «Probar nivel» abre el juego con tu diseño. El editor oficial permanecerá bloqueado hasta implementar una cuenta de propietario verificada; no se puede activar con un botón público.
